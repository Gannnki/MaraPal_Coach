# Raw data collection guide

This directory holds intermediate artifacts from source collection. To respect copyright and stay compliant, **do not** commit here:

- Original book PDF files
- Full chapter text extracted from books
- Verbatim copies of long web articles (quotations beyond a few sentences)

## Suggested subdirectory layout (create as you collect)

```
raw/
├── web_articles/       # Scraped article body text, filename includes the source URL
├── community_qa/       # Manually curated forum answers, each record has title/content/url/upvotes
└── book_summaries/     # Rewritten book summaries (not original text), each record has topic/summary/book_ref
```
